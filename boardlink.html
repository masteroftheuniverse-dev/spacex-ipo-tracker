Remote pairing & live telemetry for the Summerboard SBX2

Browser can't do Bluetooth

This page talks to your board over Web Bluetooth, which this browser doesn't support. On Android, open it in Chrome. On iPhone, Safari and Chrome both lack Bluetooth support — use the Bluefy browser from the App Store instead.

Open this page in its own tab

Bluetooth is switched off inside embedded previews. Open this address directly in Chrome as a normal tab, then connect from there.

Power the board on, then connect

Pick VESC BLE UART from the device list. That's your SBX2 — the board's Bluetooth module uses the standard VESC name.

Pair your remote

Command 37
  1. Charge the remote fully first. The lightning-bolt icon flashes while charging and goes solid when full — allow 5–6 hours. A half-charged remote won't pair.
  2. Switch the remote off, connect to the board above, and stand near it.
  3. Press Start pairing. The board opens a 10-second window.
  4. While the countdown runs, switch the remote on. Powering it up inside the window is what binds it — there is no separate pairing mode to hold down.
